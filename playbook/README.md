# iOSアプリ 公開プレイブック（アプリ共通）

ヘイドラムを実際に App Store 申請まで通した経験から、**どのアプリにも使い回せる形**にまとめたものです。

| ファイル | 中身 |
|---|---|
| `01_HANDS_ON_BUILD_TO_SUBMIT.md` | ビルド〜申請までのハンズオン（順番・リンク・画面操作・コマンド）。つまずき集つき |
| `02_SUBMISSION_KIT_PROMPT.md` | **実装が終わったらClaudeに投げるプロンプト**。申請に必要な文言・画像・ページ・回答を一式出させる |
| `03_REFERENCE.md` | 文字数上限、画像サイズ、プライバシー回答の考え方、審査で止まる典型例 |
| `tools/` | 使い回せるスクリプト（リリースガード、宣伝用スクショの文字入れ、UIテストでのスクショ撮影の雛形） |

使い方: 新しいアプリを作るときは、このフォルダをそのまま新しいリポジトリの `playbook/` にコピーする。実装完了後に `02_...` のプロンプトを Claude Code に貼る。

> 注意: 画面の名称・画像サイズ・規約は Apple / Google が随時変更します。ここに書いた値は 2026-10 時点の実体験です。**迷ったら App Store Connect の画面表示とエラー文言が正**です。
