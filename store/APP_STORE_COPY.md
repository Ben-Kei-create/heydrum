## バージョン 1.0
**プロモーション用テキスト（170）**
```
ボタンひとつで音を鳴らし、入力した文字を大きく読み上げます。離れた場所の相手にも伝わる大きな文字で表示。読み上げの開始タイミングも選べます。
```
**説明文（4000）**
```
ヘイドラムは、「音を鳴らす」と「文字を読み上げる」だけに絞った、とてもシンプルなアプリです。

■ ドラムモード
「ドラム音」と「金属音」、2つの大きなボタンをタップするだけ。連打もOKです。

■ 音声モード
読み上げたい文字を入力して「読み上げ開始」。画面いっぱいの大きな文字で表示しながら、iPhone標準の日本語音声で読み上げます。
・文字は短いほど大きく、遠くの人にも読みやすい
・「すぐ／3秒後／5秒後／10秒後／15秒後／30秒後」から開始タイミングを選べる
・一時停止、再開、もう一度読み上げ
・読み上げ中は白い画面に文字だけを表示。右下の「停止」でいつでも元の画面へ

■ 履歴
読み上げた文章は最大100件まで端末内に保存。ワンタップで再生できます。

■ 設定
・音量の調整
・日本語の音声の選択、読み上げ速度（ゆっくり／標準／速め）
・広告の非表示（買い切り）と購入の復元

■ プライバシー
入力した文章と履歴は端末の中だけに保存され、外部へ送信されません。読み上げにクラウドやAIサービスは使いません。インターネット接続がなくても、端末に日本語音声があれば読み上げできます。

※声の種類は、お使いのiPhoneにインストールされている日本語音声によって決まります。
※無料でご利用いただけます。広告を表示します（買い切りで非表示にできます）。
```

## 輸出コンプライアンス
アプリは標準の暗号化（OS/SDKのHTTPS）のみ使用 → `Config/Info.plist` に `ITSAppUsesNonExemptEncryption = NO` を設定済み（アップロード時の質問が出なくなる）。これはあなたの申告として扱われるので、内容に誤りがないか確認してください。

## App のプライバシー（要確認・最終責任はオーナー）
AdMob SDK が収集し得るデータを、Google の最新説明に沿って申告します: https://developers.google.com/admob/ios/privacy/strategies と https://support.google.com/admob/answer/10358070（Apple の申告方法: https://developer.apple.com/jp/app-store/app-privacy-details/）。目安:
| データ種別 | 収集 | 用途 | ユーザーに紐づく | トラッキング |
|---|---|---|---|---|
| 識別子（デバイスID） | はい | サードパーティ広告 | 紐づく／最新の説明で確認 | ATT を要求しない設計のため、広告IDは許可なしでは取得されない。**IDFA を使うならATTが必要**（今は未実装。ADR-012） |
| 使用状況データ（広告データ・製品操作） | はい | サードパーティ広告・分析 | 同上 | 同上 |
| 診断（クラッシュ・パフォーマンス） | はい（SDK） | アプリの機能 | — | なし |
| 購入 | Appleが処理（アプリは受け取らない） | — | — | — |
| ユーザコンテンツ（入力文） | **収集しない** | — | — | — |
「広告ID（IDFA）を使用しますか」: **はい → アプリ内で広告を配信する** にチェック（AdMob SDK が参照するため）。この欄は誤ると審査で止まるので、提出前に AdMob の最新ドキュメントと突き合わせてください。
