```
ヘイドラムは、「音を鳴らす」と「文字を読み上げる」だけに絞った、とてもシンプルなアプリです。

■ ドラムモード
「ドラム音」と「金属音」、2つの大きなボタンをタップするだけ。連打もOKです。

■ 音声モード
読み上げたい文字を入力して「読み上げ開始」。画面いっぱいの大きな文字で表示しながら、iPhone標準の日本語音声で読み上げます。
・文字は短いほど大きく、遠くの人にも読みやすい
・「すぐ／3秒後／5秒後／10秒後／15秒後／30秒後」から開始タイミングを選べる
・一時停止、再開、もう一度読み上げ
・読み上げ中は白い画面に文字だけを表示。右下の「停止」でいつでも元の画面へ

■ 履歴
読み上げた文章は最大100件まで端末内に保存。ワンタップで再生できます。

■ 設定
・音量の調整
・日本語の音声の選択、読み上げ速度（ゆっくり／標準／速め）
・広告の非表示（買い切り）と購入の復元

■ プライバシー
入力した文章と履歴は端末の中だけに保存され、外部へ送信されません。読み上げにクラウドやAIサービスは使いません。インターネット接続がなくても、端末に日本語音声があれば読み上げできます。

※声の種類は、お使いのiPhoneにインストールされている日本語音声によって決まります。
※無料でご利用いただけます。広告を表示します（買い切りで非表示にできます）。
```

根拠: Google Mobile Ads SDK の公式開示 https://developers.google.com/admob/ios/privacy/data-disclosure （2026-10-20 確認。IPアドレス／デバイスID／広告データ／製品操作／クラッシュ／パフォーマンス）。Appleの定義: https://developer.apple.com/jp/app-store/app-privacy-details/

### チェックを入れない（すべて「収集しない」）
連絡先情報（名前・メール・電話・所在地・その他）/ 健康とフィットネス（両方）/ 財務情報（3つ）/ 位置情報の「詳細な位置情報」/ 機密情報 / 連絡先 / **ユーザコンテンツ（8項目すべて：入力した文章は端末内のみで送信しません）** / 閲覧履歴 / 検索履歴 / ユーザID / **購入**（課金はAppleが処理し、アプリは受け取りません）/ その他の使用状況データ / その他の診断データ / 周囲 / 身体 / その他のデータ。

### トラッキングについて（B案の実装内容）
- アプリは **ATT（App Tracking Transparency）の許可画面を実装済み**。表示順: 同意フォーム（UMP）→ ATT許可 → 広告SDK起動。課金済みの人・同意しない人には出ない。許可しなくても全機能が使える。
- 許可画面の説明文（Info.plist `NSUserTrackingUsageDescription`）: 「広告をお客様に合ったものにするために、広告識別子を使用します。許可しなくてもアプリの機能はすべて使えます。」
- 「トラッキングに使う？」は、Appleの定義（他社のアプリ・サイト等のデータと広告目的で紐づける）に基づく**保守的な「はい」**。Googleの公式ページは区分を明示していないため、最終判断はオーナー（あなた）。App Store Connect で「トラッキングに使用するデータ」が表示されることをプライバシー欄で確認。
- トラッキング用ドメイン: アプリ自身の `PrivacyInfo.xcprivacy` は `NSPrivacyTracking=true`（SDK側のマニフェストがドメインを宣言）。

### 続く質問の回答
