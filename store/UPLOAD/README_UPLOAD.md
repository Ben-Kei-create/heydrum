# アップロードするものはここにまとめてあります

App Store Connect > 対象App > iOS App バージョン 1.0 > 「プレビューとスクリーンショット」。
**サイズごとに別の欄**があります。審査には、次の **2つのサイズの両方**が必要です（App Store Connect のエラー表示に従う）:

| 置き場所 | 画像サイズ | App Store Connect の欄 | 備考 |
|---|---|---|---|
| `1a_screenshots-6.9in/` | 1320×2868 | **6.9インチ**ディスプレイ | 宣伝用（文字入り）7枚。番号順 |
| `1b_screenshots-6.3in/` | 1206×2622 | **6.3インチ**ディスプレイ（Dynamic Island搭載の中型） | 宣伝用（文字入り）7枚。番号順 |
| `1c_plain-alternative-6.9in/`, `1d_plain-alternative-6.3in/` | 同上 | 同上 | 文字なし（画面そのまま）。1a/1b の代わり。**混ぜない** |
| `2_app-preview/heydrum-app-preview-6.9in-886x1920.mp4` | 886×1920 | アプリプレビュー（6.9インチ欄） | 任意。**古い画面（中央ボタンあり）のまま**なので、使うなら撮り直しを推奨 |
| `3_iap-review/iap-review-settings.png` | 1320×2868 | アプリ内課金 > 審査情報 | 必須（初回の課金） |
| `4_icon-reference/app-icon-1024.png` | 1024×1024 | アップロード不要 | 控え |

- 6.5インチ・6.1インチ等の欄が別に出た場合は、6.9インチか6.3インチの画像を拡大縮小して使えるか確認される（出ない場合は不要）。
- iPad は非対応（iPhone専用）なので不要。
- コピペ文言は `../submission-kit.html`（ブラウザで開く）。
