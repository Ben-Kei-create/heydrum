# 第4章 アプリ内課金（非消耗型）を作る

この章は、「広告を消す」などの**買い切り**の課金を入れる人向けです。課金を入れない人は、第5章へ進んでください。

## 4-1 なぜ非消耗型か

アプリ内課金には、いくつかの種類があります。

| 種類 | 意味 | 向く例 |
|---|---|---|
| 消耗型 | 使うとなくなる（何度も買える） | ゲームの通貨 |
| **非消耗型** | **一度買えばずっと使える** | **広告を消す、機能の解放** |
| 自動更新サブスクリプション | 期間ごとに自動で更新 | 月額のサービス |

「広告を消す」の買い切りは、非消耗型です。**購入の復元**（機種変更や再インストールのあとで、買ったものを取り戻す機能）も、非消耗型では必須の扱いです。

## 4-2 商品を作る

1. App Store Connectで、対象のアプリを開く。
2. 「収益化」→「アプリ内課金」→「+」。
3. 種類は「**非消耗型**」。
4. 次を入力する。

| 項目 | 入れるもの |
|---|---|
| 参照名 | 自分用の名前（例 `広告を非表示`）。ユーザーには見えない。 |
| **製品ID** | **`<Bundle ID>.remove_ads` のような文字列。登録後は変更できない。** |
| 価格 | 好きな金額。コードに金額は書かない。 |
| 表示名（30文字まで） | 例 `広告を非表示` |
| 説明（45文字まで） | 例 `広告を非表示にします（買い切り）` |
| ファミリー共有 | 通常はオフ |
| 審査用のスクリーンショット | 購入ボタンが写っている画面（設定画面など） |
| 審査メモ | 例 `設定タブの「広告を非表示にする」から購入できます。` |

### 製品IDの決め方

製品IDは、あとで変えられません。`<Bundle ID>.remove_ads` のように、**意味が分かる名前**にします。コードの中に直接書かず、設定ファイル（第6章）から読むようにしてください。

### 価格のコードへの持ち込み方

**画面に出す価格は、StoreKitが返す表示用の価格（`displayPrice`）をそのまま使います。** 金額をコードに書くと、国ごとの価格や、あとから変えた価格と、ずれます。

## 4-3 権利の判定は、StoreKitの検証済みの記録だけで行う

「このユーザーは、広告を消す権利を持っているか」の判定は、**UserDefaultsに保存した印ではなく、StoreKitの検証済みの取引（`Transaction.currentEntitlements`）**で行います。

- 検証に失敗した取引は、権利を与えない。
- 返金（取り消し）された取引は、権利を外す。
- 起動時と、アプリがフォアグラウンドに戻ったときに、再確認する。
- **「購入を復元」ボタンを押したときだけ**、`AppStore.sync()` を呼ぶ。起動のたびに呼ぶと、Apple IDのパスワードを求められてしまう。

## 4-4 テストの方法

- **Xcodeの StoreKit Configuration ファイル**（`.storekit`）を作り、商品を定義する。実際のApp Storeに接続せずに、購入、キャンセル、保留、返金、復元を試せる。
- 単体テストから、`StoreKitTest` の `SKTestSession` を使うと、購入や返金を自動で試せる。
- 本番の商品IDは、App Store Connectに登録したものを、Releaseの設定に入れる（第6章）。
- **TestFlightで、サンドボックスの購入**を試す。実際の請求は発生しない。

### 実体験のつまずき

- StoreKitのテストが、**シミュレータの状態によって**、最初の1回だけ失敗することがあった。商品の読み込みを数回やり直すと安定した。
- 失敗を注入するAPIが、古い書き方（`failTransactionsEnabled`）は非推奨になっていて、`setSimulatedError` に変える必要があった。

## ハンズオン：非消耗型の商品を作って、テストする

| # | やること | 入れる値の例 | 成功の目安 |
|---|---|---|---|
| 1 | 「収益化」→「アプリ内課金」→「+」→ 非消耗型 | 参照名 `広告を非表示`／製品ID `com.yourname.mymemo.remove_ads` | 商品の画面が開く |
| 2 | 表示名・説明を入れる | `広告を非表示`／`広告を非表示にします（買い切り）` | 文字数エラーが出ない（30字、45字） |
| 3 | 価格を選ぶ | 任意（あとで変えられる） | 価格が表示される |
| 4 | 審査用スクリーンショットと審査メモを入れる | 設定画面の画像／`設定タブの「広告を非表示にする」から購入できます。` | 状態が「メタデータが不足」でなくなる |
| 5 | Xcodeで `.storekit` を作り、商品を定義する（製品IDは、3と同じ） | 同上 | スキームの設定で、StoreKit Configuration を選べる |
| 6 | シミュレータで購入ボタンを押す | — | 購入のダイアログが出て、購入後に「購入済み」の表示になる |
| 7 | 「購入を復元」を押す（購入済みの状態で） | — | 認証を求められず、状態が変わらない（起動時には、押されていないこと） |

**確認：** 価格の表示が、`.storekit` の価格（例 480円）と一致していれば成功です。

## 4-5 この章のチェックリスト

```
□ 非消耗型の商品を作った
□ 製品IDを控えた（変更できない）
□ 表示名、説明、審査用スクリーンショットを入れた
□ 価格は StoreKit の displayPrice を表示している
□ 権利は、検証済みの取引だけで判定している
□ 復元ボタンを押したときだけ AppStore.sync() を呼ぶ
□ StoreKit Configuration で購入、保留、返金を試した
```
