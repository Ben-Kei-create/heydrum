# 第3章 Bundle ID と、App Store Connectのアプリを作る

## 3-1 Bundle IDを決めて登録する

Bundle IDは、アプリを一意に識別する名前です。**一度登録したら変更できません。** 慎重に、でも悩みすぎずに決めます。

### 決め方

- 逆ドメイン形式にする：`com.yourname.appname`
- 持っているドメインがあれば、それを逆にする。なければ、自分の名前や屋号を使う（実際に使うドメインでなくてもよい）。
- 英数字とハイフン、ドットだけを使う。
- 例：`com.yourname.myapp`

### 登録の手順

1. <https://developer.apple.com/account/resources/identifiers/list> を開く。
2. 「+」を押す。
3. 「App IDs」を選び、続けて「App」を選ぶ。
4. **Description**：アプリの名前（日本語でもよい）。
5. **Bundle ID**：「Explicit」を選び、上で決めた文字列を入れる。
6. Continue → Register。

この段階で、使う機能（Capabilities）の追加は、必須ではありません。アプリ内課金は、後述の商品を作れば使えます。

## 3-2 App Store Connectで「新規App」を作る

1. <https://appstoreconnect.apple.com/apps> を開く。
2. 「+」→「新規App」。
3. 次の項目を入れる。

| 項目 | 入れるもの |
|---|---|
| プラットフォーム | iOS（macOSやtvOSは、使うときだけ） |
| 名前 | App Storeに表示される名前（30文字まで）。**他のアプリと重複すると使えない。** |
| プライマリ言語 | 日本語 |
| バンドルID | 3-1で登録したもの。一覧に出ないときは、画面を再読み込みする。 |
| SKU | 管理用の文字列。ユーザーには見えない。例 `appname-001` |
| ユーザアクセス | アクセス制限なし |

### 名前についての注意

**アプリの名前は、App Storeの全体で重複できません。** 希望の名前がすでに使われていると、登録できないことがあります。筆者のアプリでは、日本語の正式名称は「ヘイドラム」ですが、App Store Connect上に登録した名前は、英字の表記でした。こうしたときに知っておくと役に立つ点が一つあります。

- **ホーム画面に表示される名前は、App Storeの名前とは別に決められる。** アプリの中の表示名（Info.plistの `CFBundleDisplayName`）が、ホーム画面に出ます。App Store上の名前が希望どおりにならなくても、ホーム画面の名前は、希望のままにできます。
- 希望の名前が使えないときは、表記を少し変える（記号、英字の併記など）。

### 注意：Bundle IDの一覧に出ないとき

- Developerサイトで、まだ登録していない。
- 登録した直後で、画面の再読み込みが必要。
- 別のTeamで登録している。

## 3-3 アプリの情報の最初の入力

アプリを作ったら、次の項目を先に埋めておくと、後が楽です（詳しくは、第9章）。

- サブタイトル（30文字まで）
- カテゴリ（プライマリ、セカンダリ）
- 年齢制限（質問に答える）
- 著作権表記（例 `2026 Your Name`）

## ハンズオン：アプリの「器」を作る

例として、架空のアプリ「マイメモ」を作るつもりで進めます（あなたのアプリの名前に置き換えてください）。

| # | やること | 入れる値の例 | 成功の目安 |
|---|---|---|---|
| 1 | Identifiers →「+」→ App IDs → App | Description `マイメモ`／Bundle ID（Explicit）`com.yourname.mymemo` | 一覧に、新しい行が追加される |
| 2 | App Store Connect →「新規App」 | プラットフォーム iOS／名前 `マイメモ`／言語 日本語／SKU `mymemo-001`／ユーザアクセス 制限なし | アプリの画面（バージョン 1.0）が開く |
| 3 | バンドルIDの選択欄で、1で作ったものを選ぶ | `マイメモ - com.yourname.mymemo` | 「作成」が押せる |
| 4 | 名前が重複していたら、表記を変える | `マイメモ！` など | エラーが消える |

**確認：** App Store Connectの「マイApp」に、アプリのアイコン枠（まだ空）が並べば成功です。

## 3-4 この章のチェックリスト

```
□ Bundle ID を決めて登録した（変更できない）
□ App Store Connect で新規アプリを作った
□ SKU とアプリ名を決めた
□ ユーザアクセスを選んだ
```

## この章のつまずき

| 症状 | 原因と対処 |
|---|---|
| 新規アプリのバンドルIDの一覧に出ない | Developerサイトで未登録、または再読み込みが必要。 |
| 名前が使えない | 他のアプリが使っている。表記を変える。ホーム画面の表示名は別に決められる。 |
| 後で、Bundle IDを変えたくなった | 変更できない。新しいBundle IDで、新しいアプリを作ることになる。 |
