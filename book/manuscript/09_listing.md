# 第9章 ストアに載せる情報

この章は、App Storeの商品ページに出る文章と、入力欄の上限をまとめたものです。

## 9-1 入力欄の文字数の上限

| 項目 | 上限 | 見える場所 |
|---|---|---|
| 名前 | 30文字 | 商品ページ、検索結果 |
| サブタイトル | 30文字 | 名前の下 |
| プロモーション用テキスト | 170文字 | 説明文の上。**審査なしで、いつでも変更できる** |
| 説明文 | 4,000文字 | 商品ページ |
| キーワード | 100文字（半角カンマ区切り） | 見えない。検索に使われる |
| このバージョンの最新情報 | 4,000文字 | 商品ページ |
| 課金商品の表示名 | 30文字 | 購入の画面 |
| 課金商品の説明 | 45文字 | 購入の画面 |

文字数は、**日本語も、1文字を1つ**と数えます。

## 9-2 サブタイトル

名前を補う、短い一言です。**機能の中身が伝わる**ものにします。例：「2つの音と、大きな文字の読み上げ」。

## 9-3 説明文

次の順に書くと、読みやすくなります。

1. 一文で、何のアプリか。
2. 機能を、短い箇条書きで。
3. プライバシー（収集しないものを、はっきり）。
4. 注意書き（「声は端末の音声によって決まります」など、期待とのずれを防ぐ）。
5. 料金（「無料。広告あり。買い切りで非表示にできます」）。

**書いてはいけないこと**：実際にはできないこと、他社の名前を勝手に使うこと、「No.1」のような根拠のない表現、他のアプリの宣伝。

### 実体験：期待とのずれを書いておく

筆者のアプリは、「読み上げの声」が、端末の音声で決まります。声の種類を保証できないので、説明文に、**「声の種類は、お使いのiPhoneにインストールされている日本語音声によって決まります」**と書きました。審査でも、誤解を招く表現を避けることが、安全です。

## 9-4 キーワード

- 100文字以内、**半角のカンマ**で区切る（スペースは入れない）。
- 名前やサブタイトルにある単語は、重ねて入れなくてよい。
- 複数形や言い換えを、1つの欄に並べる。

例：`読み上げ,音声,テキスト,大きな文字,ドラム,効果音,アナウンス,音読,タイマー`

## 9-5 カテゴリと年齢制限

- **カテゴリ**：プライマリを1つ、セカンダリを1つ（任意）。内容に合うものを選ぶ。
- **年齢制限**：質問に答えると、自動で決まる。暴力、ギャンブル、成人向けの内容などが**ない**なら、すべて「なし」で、4+になる。

## 9-6 著作権、サポートURL、ポリシーURL

| 項目 | 入れるもの |
|---|---|
| 著作権 | `2026 あなたの名前` のような形 |
| サポートURL | 第7章で公開した、連絡先つきのページ（**必須**） |
| プライバシーポリシーURL | 第7章で公開した、ポリシーのページ（**必須**） |
| マーケティングURL | 任意。空欄でよい |

## 9-7 コンテンツ配信権

「このアプリは、サードパーティ製のコンテンツを含む、表示する、またはそれにアクセスしますか？」という質問です。

| 選ぶもの | 当てはまる場合 |
|---|---|
| 「はい。…必要な権利を保有しています」 | 他人が作った素材（フォント、画像、音、動画）を使っている。**広告のSDKが、広告を表示する場合も、この選択肢が当てはまる。** |
| 「いいえ」 | 自分で作った素材だけで、広告などの第三者のコンテンツもない。 |

### 実体験

筆者は、最初、「いいえ」の準備をしていました。ところが、あとで、**オープンライセンスのフォントを3つ同梱**したため、答えが変わりました。答えは、**アプリの中身が変わるたびに、見直す**必要があります。

### 素材のライセンスを守る

- **SIL Open Font License（OFL）**：同梱と再配布ができる。著作権表示と、ライセンスの全文を、一緒に配る必要がある。
- **Apache License 2.0**：同梱と再配布ができる。ライセンスの全文を付ける。
- アプリの中に、「設定 > ライセンス」のような画面を作り、**全文を表示する**のが、確実です。
- フォントのファイルを、**改変せずに**使う。

## 9-8 審査メモ（App Review Information）

審査担当への連絡欄です。次のことを書くと、誤解を減らせます。

- アプリの主な機能と、**外部のサービスを使わないこと**（使わないなら）。
- 課金と広告の説明。
- ログインが不要なこと（不要なら、「サインインが必要」をオフに）。
- 連絡先（氏名、電話番号、メール）。**電話番号は、日本なら国番号を付けて、先頭の0を取る**（例 `090-1234-5678` → `+81 90 1234 5678`）。

## 9-9 価格と配信

- 価格：無料、または有料。**アプリ内課金のあるアプリでも、本体は無料にできる。**
- 配信する国：日本だけで始められる。あとから増やせる。
- リリース方法：**審査が通ったら自動で公開**、または、**手動で公開**。最初は、手動にして、公開のタイミングを自分で決めるのがおすすめ。

## ハンズオン：文字数を確かめながら、ストアの文言を入れる

| # | やること | 成功の目安 |
|---|---|---|
| 1 | サブタイトルを、30文字以内で書く | 入力欄の右に、残りの文字数が出る |
| 2 | 説明文の下書きを作り、文字数を数える（例：`wc -m`） | 4,000以内 |
| 3 | キーワードを、半角カンマで区切って100文字以内にする | 入力欄で、エラーが出ない |
| 4 | カテゴリ、年齢制限の質問に答える | 年齢が「4+」などと、自動で決まる |
| 5 | サポートURLとポリシーURLを入れる | どちらも、形式のエラーが出ない |
| 6 | コンテンツ配信権を、アプリの中身に合わせて選ぶ | 選択が保存される |

**確認：** 付録Gに、実際の入力例（ヘイドラムの文言）があります。見比べると、書き方がつかめます。

## 9-10 この章のチェックリスト

```
□ 名前、サブタイトル、説明文、キーワード、最新情報を、上限内で書いた
□ 説明に、実際にはできないことを書いていない
□ 期待とのずれ（声の種類など）を、説明に書いた
□ カテゴリ、年齢制限、著作権を入れた
□ サポートURLとポリシーURLを入れた
□ コンテンツ配信権を、アプリの中身に合わせて答えた
□ 素材のライセンス（OFLなど）の全文を、アプリの中に載せた
□ 審査メモと連絡先（電話は +81 の形）を書いた
□ 価格、配信国、リリース方法を決めた
```
