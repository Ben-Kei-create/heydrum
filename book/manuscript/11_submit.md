# 第11章 審査に出す

## 11-1 提出前の、最後の確認

App Store Connectの、バージョンの画面を、**上から順に**見ていきます。赤い表示が、1つも残らないようにします。

| 場所 | 確認すること |
|---|---|
| プレビューとスクリーンショット | 必要なサイズの欄が、すべて埋まっている |
| 説明文、キーワード、サポートURL | 入っている。サポートURLは、日本語の欄に |
| ビルド | アップロードしたビルドを選んで、保存した |
| アプリのプライバシー | 回答して、**公開した** |
| アプリ情報 | カテゴリ、年齢制限、ポリシーURL、コンテンツ配信権 |
| アプリ内課金 | 商品の情報と、審査用のスクリーンショット |
| App Review情報 | 連絡先、メモ、サインインの要否 |
| 価格と配信 | 価格、国、リリース方法 |

## 11-2 「審査用に追加できません」と言われたら

画面の右上の「**審査用に追加**」を押すと、足りないものがあれば、**一覧で、項目名が表示**されます。筆者が実際に出会ったメッセージを、順番に並べます。

| 表示 | 対処 |
|---|---|
| ビルドを選択してください | 第8章：バージョン画面で、ビルドを選んで保存 |
| 日本語 - サポートURL - このフィールドは必須です | 第7章：公開したサポートページのURLを入れる |
| Dynamic Island搭載iPhone（中型ディスプレイ）用のスクリーンショットが必要 | 第10章：6.3インチの欄に画像を入れる |
| プライバシーポリシーのURLの形式が正しくありません | 第7章：`https://` から始まる公開URLにする |

メッセージは、**そのまま、次にやることを教えてくれます。** 慌てずに、1つずつ消していきます。

## 11-3 提出の操作

1. すべての項目が埋まったら、「審査用に追加」→「審査に提出」。
2. 画面が、「審査待ち」に変わる。

### 提出したあと、してはいけないこと

- **提出をキャンセルして、編集し直す**と、審査の順番が、最後に回ることがあります。直したくなっても、まず、審査の結果を待ちます（ただし、重大な誤りに気付いたときは、別です）。

## 11-4 審査の状態

| 状態 | 意味 |
|---|---|
| 提出準備中 | まだ提出していない |
| 審査待ち | 順番を待っている |
| 審査中 | 審査担当が見ている |
| 承認待ちのリリース／配信準備完了 | 承認された。手動リリースなら、あなたが公開する |
| 却下 | 指摘があった。メッセージを読む（第12章） |
| バイナリが無効 | 第12章（却下されたバージョンの表示のことがある） |

目安は、24〜48時間です。結果は、Appleのメールで届きます。

## 11-5 提出の前に、TestFlightで試す

提出の前に、**TestFlight**で、実機に入れて動かすと、見つかる不具合があります。

- 自分のApple IDで、**内部テスター**に追加される（審査なしで、すぐ使える）。
- iPhoneの「TestFlight」アプリから、インストールする。
- 課金は、**サンドボックス**になり、実際の請求は発生しない。
- 広告、同意の画面、ATTの許可、機内モードでの動作を、**実機**で確かめる。

シミュレータでは、確かめられないことが、たくさんあります。たとえば、実機の声の質、実際の広告の配信、実際の課金。**シミュレータで確認できたことと、実機で確認できたことを、混ぜて「確認済み」としない**でください。

## ハンズオン：「審査用に追加」のエラーを、全部消す

| # | やること | 成功の目安 |
|---|---|---|
| 1 | バージョンの画面を、一番上から、赤い表示を探す | 赤い表示の場所が分かる |
| 2 | 「審査用に追加」を押し、エラーの一覧を、読む | 項目名が、そのまま出る |
| 3 | 一覧の項目を、**1つずつ**直す（表11-2を見る） | 直すたびに、一覧が短くなる |
| 4 | もう一度、「審査用に追加」を押す | **エラーの一覧が出ず、提出の確認の画面が出る** |
| 5 | 「審査に提出」を押す | 状態が「審査待ち」になる |

**確認：** 状態が「審査待ち」になったら、**申請の完了**です。

## 11-6 この章のチェックリスト

```
□ バージョン画面の赤い表示を、すべて消した
□ アプリのプライバシーを「公開」した
□ 「審査用に追加」で、一覧が出なくなるまで直した
□ 提出後は、むやみにキャンセルしない
□ TestFlightで、実機の確認をした（またはしていないと分かっている）
```
