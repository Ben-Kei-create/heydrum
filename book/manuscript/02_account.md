# 第2章 アカウントと契約：最初に、待ち時間のあるものを

## 2-1 Apple Developer Program に加入する

アプリをApp Storeに出すには、Apple Developer Programへの加入（年額）が必要です。

- 加入の入口：<https://developer.apple.com/programs/enroll/>
- 金額は、国や時期で変わります。米国では年99ドルが目安ですが、日本円の金額はApple公式で確認してください。
- 個人で加入するか、法人（屋号）で加入するかを選べます。**個人で加入すると、App Storeの販売元として、あなたの氏名が表示されます。** 氏名を出したくないなら、法人としての加入が必要で、そのための手続き（D-U-N-S番号など）が増えます。ここは、あとから変えにくい判断です。

加入が完了したら、<https://developer.apple.com/account> で、**Team ID**（10桁）を確認できます。後でXcodeの署名の設定に使います。

## 2-2 有料App契約（Paid Applications）を承認する

**この手続きを後回しにすると、あとで必ず止まります。** 筆者の場合、課金商品を作ろうとした画面で、次のメッセージに行き当たりました。

> 更新された有料Appの契約（Paid Applications Schedule）を確認してください。アプリを更新する、アプリ内課金を新規作成する、新しいアプリを提出するには、法的役割（Account Holder）のユーザーが、ビジネスモジュールで契約を確認し、承認する必要があります。

### やること

1. 先に、<https://developer.apple.com/account> で、最新の Apple Developer Program License Agreement に同意する。画面の上に、更新の案内が出ていることがあります。
2. 次に、App Store Connectの「ビジネス」を開く：<https://appstoreconnect.apple.com/business>
3. 「契約」から、**有料App契約（Paid Applications）**を開いて、内容を確認し、承認する。
4. 同じ画面で、**銀行口座**と**税務情報**の入力を求められることがある。

### 注意すること

- **承認できるのは、Account Holder（法的役割）だけ。** 個人で加入していれば、あなたです。チームなら、アカウントの所有者に頼みます。
- 無料のアプリでも、**アプリ内課金を作るなら必須**です。
- 口座や税務の入力が終わるまで、契約の状態が「処理中」のままのことがありますが、課金商品の作成は、契約が有効になれば進められます。
- **口座番号、税務情報（マイナンバーに相当するものなど）は、個人情報です。AIには入力させず、あなた自身で入力してください。**

## 2-3 App Store Connectのユーザアクセス

新しいアプリを作るとき、「ユーザアクセス」という項目が出ます。

| 選択肢 | 意味 |
|---|---|
| アクセス制限なし | チームの全員が、このアプリを扱える。 |
| アクセス制限あり | 指定した人だけが扱える。 |

**個人開発なら「アクセス制限なし」で問題ありません。** 複数人のチームで、担当を分けたいときだけ「制限あり」にします。

## ハンズオン：契約を、手を動かして確かめる

| # | やること | 成功の目安（画面にこう出る） | 失敗したら |
|---|---|---|---|
| 1 | <https://developer.apple.com/account> を開く | 「メンバーシップの詳細」に、**Team ID（10桁の英数字）**が出る | 加入が完了していない。2-1に戻る |
| 2 | Team ID を、メモに控える | 自分のメモに、10桁がある（**gitやAIの会話には、貼らない**） | — |
| 3 | <https://appstoreconnect.apple.com/business> →「契約」を開く | 「有料App契約」の行が見える | 行がない：Developerサイトで、ライセンス契約に同意する |
| 4 | 有料App契約を開き、内容を確認して承認する | 状態が「**有効**」（または、口座入力待ちの表示）に変わる | ボタンが出ない：Account Holder のアカウントか確認 |
| 5 | 口座と税務情報を入力する（自分で） | 「口座」「税務」の状態が、完了になる | 入力途中の表示は、課金商品の作成を止めないことが多い |

**ここまで終われば、第3章に進めます。** 契約の状態が「有効」になっていない場合は、ここで止めて、状態の表示を、そのまま読んでください。

## 2-4 この章のチェックリスト

```
□ Apple Developer Program に加入した
□ 最新のライセンス契約に同意した
□ 有料App契約を承認した（Account Holder）
□ 口座と税務情報を入力した（自分で）
□ Team ID を控えた
```

## この章のつまずき

| 症状 | 原因と対処 |
|---|---|
| 課金商品が作れない／アプリの更新ができない | 有料App契約が未承認。2-2の手順。 |
| 契約の画面に、承認のボタンが出ない | Account Holder以外でログインしている。所有者に頼むか、所有者のアカウントで操作する。 |
| 契約を承認できない | 先に、Developerサイトで最新のライセンス契約に同意する。 |
