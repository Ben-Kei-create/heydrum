# 第10章 スクリーンショットとプレビュー動画

## 10-1 何枚、どのサイズが必要か

App Store Connectの「**プレビューとスクリーンショット**」の欄は、**画面のサイズごとに別の欄**になっています。ここで、筆者は止まりました。最初は、6.9インチのサイズだけを用意しました。ところが、提出しようとすると、次のように言われました。

> Dynamic Island搭載iPhone（中型ディスプレイ）用のスクリーンショットをアップロードする必要があります。

これは、**6.3インチ**の欄です。**2つのサイズ（6.9インチと6.3インチ）の両方**を求められました。

| 欄の名前 | 画像のサイズ（ピクセル、縦向き） | 筆者の使った端末 |
|---|---|---|
| 6.9インチ | 1320 × 2868 | iPhone Pro Max クラスのシミュレータ |
| 6.3インチ（Dynamic Island搭載の中型） | 1206 × 2622 | iPhone Pro クラスのシミュレータ |

![同じ画面を、6.9インチ用（左）と6.3インチ用（右）に撮り分けた宣伝用の画像の例。サイズが違い、同じスクリプトで作れる](images/fig-screens.jpg)

- 1つのサイズの画像を、別のサイズの欄に使い回せるとは限りません。**欄ごとに、サイズの合う画像**を求められることがあります。
- 枚数は、1つの欄に、**1〜10枚**。最初の3枚が、検索結果で目立ちます。
- **iPhone専用のアプリなら、iPadの画像は不要**です。
- サイズの要件は変わります。**画面にサイズが出るので、それに従ってください。**

## 10-2 実機でなく、シミュレータで撮る

実機でも撮れますが、**シミュレータとUIテストで撮る**と、何度でも、同じ条件で撮り直せます。

### ステータスバーを、きれいにする

シミュレータのステータスバーには、本物の時刻や電波の表示が出ます。App Storeの画像では、**時刻を「9:41」に、電池を満タンに**するのが慣例です。コマンドで変えられます。

```sh
xcrun simctl status_bar booted override \
  --time "9:41" --batteryState charged --batteryLevel 100 \
  --cellularMode active --cellularBars 4 --wifiBars 3 --operatorName ""
```

終わったら、`xcrun simctl status_bar booted clear` で戻します。

### UIテストで、画面を自動で撮る

画面を手で操作して撮る代わりに、**UIテスト（XCUITest）に、画面の遷移と撮影を書きます。**

```swift
final class ScreenshotTests: XCTestCase {
    func testCaptureAll() {
        let app = XCUIApplication()
        app.launchArguments = ["-uitest", "-uitest-purchased", "-uitest-history-sample"]
        app.launch()
        shot("01-home")
        app.buttons["homeDrumCard"].tap()
        shot("02-drum")
        // …
    }

    private func shot(_ name: String) {
        Thread.sleep(forTimeInterval: 0.8)   // アニメーションが落ち着くのを待つ
        let dir = ProcessInfo.processInfo.environment["SHOT_DIR"] ?? ""
        try? app.screenshot().pngRepresentation
            .write(to: URL(fileURLWithPath: "\(dir)/\(name).png"))
    }
}
```

実行は、書き出し先を環境変数で渡します。

```sh
TEST_RUNNER_SHOT_DIR=$PWD/shots xcodebuild -project App.xcodeproj -scheme App \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro Max' \
  -only-testing:AppUITests/ScreenshotTests test
```

### 撮影用の、決まったデータ

- 起動の引数で、**撮影用のデータ**（履歴のサンプルなど）を差し込めるようにしておく。実際のユーザーの情報を、画面に出さない。
- 広告枠は、**購入済みの状態**で撮ると、枠が出ず、きれいな画像になる（ただし、実際の画面と食い違わない範囲で）。
- 広告やダミーの文字を、**偽物の広告として描かない**。

## 10-3 文字入りの宣伝画像にする

画面そのままの画像でも提出できますが、**短い見出しの付いた画像**のほうが、内容が伝わります。筆者は、背景色の上に、見出しの文字と、角を丸めた画面を重ねる、小さな画像生成のスクリプト（Swift、CoreGraphics）を作りました。サイズは、元の画像から自動で決める仕組みにして、**同じスクリプトで、6.9インチと6.3インチの両方**を作れます。

- 見出しは、**2行以内**、1行は十数文字まで。
- 見出しの内容は、**機能の価値**（「遠くの人にも届く大きな文字」）。操作の説明ではない。
- 画面の中身を、**偽って見せない**。アプリにない機能を、画像で見せてはいけない。

## 10-4 アプリプレビュー（動画）

任意です。入れなくても、提出できます。

- 長さは、15〜30秒。
- 縦向き。サイズは、画面のサイズの欄ごとに決まっている。筆者が作ったのは、886 × 1920 のもの。
- 形式は、H.264のMP4またはMOV。音声のトラックがあると、安心（無音でよい）。

### 注意：動画は、画面の録画であること

Appleの方針では、**アプリプレビューは、アプリの実際の動作を録画したもの**でなければなりません。静止画をつないだスライドショーを出すと、**審査で、指摘される恐れ**があります。筆者は、シミュレータの録画が、何度も不安定になり、いったん、静止画をつないだ動画を作りました。**そのため、実際の提出には、使いませんでした。** 動画を出すなら、実機の画面収録（コントロールセンターの録画）で撮るのが、確実です。

### 録画のつまずき

`xcrun simctl io <デバイス> recordVideo` で、シミュレータを録画できます。ただし、次のことがありました。

- 録画の停止は、**そのプロセスに SIGINT を送る**必要がある。送らないと、ファイルが壊れる（再生できない）。
- パソコンの負荷が高いと、UIテストが極端に遅くなり、**録画が、数十倍の長さ**になることがある。
- 動画は、あとから**ffmpeg**で、トリミング、速度変更、サイズ変更ができる。

```sh
ffmpeg -i raw.mov -vf "trim=start=14:end=54,setpts=(PTS-STARTPTS)/1.4,fps=30,scale=886:1925,crop=886:1920,format=yuv420p" \
  -c:v libx264 -crf 18 -movflags +faststart out.mp4
```

## 10-5 アイコン

- 1024 × 1024のPNG。**透過なし**（角を丸めない。iOSが丸める）。
- アセットカタログの「AppIcon」に入れれば、必要なサイズは、Xcodeが作る。
- App Store Connectで、アイコンを別にアップロードする必要はない（ビルドに入ったものが使われる）。
- 著作権のある画像、他人の顔写真、他社のロゴを使わない。AIで画像を作った場合は、そのサービスの利用規約で、**商用利用が許されるか**を確かめる。

## ハンズオン：UIテストで、スクリーンショットを撮る

| # | やること | 成功の目安 |
|---|---|---|
| 1 | シミュレータを起動し、ステータスバーを9:41にする（`simctl status_bar override`） | シミュレータの時刻が、9:41になる |
| 2 | `ScreenshotTests` を作り、画面を3つ撮る | テストが成功する |
| 3 | 環境変数 `TEST_RUNNER_SHOT_DIR` を付けて実行する | 指定したフォルダに、PNGが3枚できる |
| 4 | `sips -g pixelWidth -g pixelHeight 画像.png` で、サイズを確かめる | 6.9インチなら `1320` × `2868` |
| 5 | もう一台（6.3インチ）のシミュレータで、同じテストを実行する | `1206` × `2622` の画像ができる |
| 6 | App Store Connectの、それぞれの欄に、アップロードする | 画像のサムネイルが、並ぶ |

**確認：** サイズの欄ごとに、画像が並べば成功です。

## 10-6 この章のチェックリスト

```
□ 画面のサイズごとの欄（6.9、6.3）に、サイズの合う画像を入れた
□ 時刻9:41、電池100%に整えた
□ UIテストで撮り、撮り直せるようにした
□ 実在の個人の情報を、画面に出していない
□ 見出しは、アプリにある機能の価値だけを書いた
□ アプリプレビューは、実機の録画か、入れない
□ アイコンは、1024×1024、透過なし
```
