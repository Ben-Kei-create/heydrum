# KDP（Kindle Direct Publishing）で出版する：申請までのハンズオン

この本を、Kindle本として出版するまでの手順です。**KDPの画面の操作は、あなた自身が行います**（ログイン、税務、口座、公開の判断）。ここには、入力する文字、ファイル、順番、リンクを揃えてあります。

## 用意したもの

| もの | 場所 | KDPのどこで使うか |
|---|---|---|
| 原稿（EPUB） | `book/dist/app-store-shinsei-handson.epub` | コンテンツ → 原稿のアップロード |
| 表紙（1600×2560 JPEG） | `book/images/cover.jpg` | コンテンツ → 表紙のアップロード |
| 登録キット（コピペ） | `book/kdp/kdp-kit.html`（ブラウザで開く）／`KDP_KIT.md` | 詳細、キーワード、カテゴリ、価格の各欄 |
| 原稿のソース | `book/manuscript/*.md` | 直したいとき |
| ビルドのスクリプト | `book/tools/` | EPUBと登録キットを作り直す |

## 著者名（ペンネーム）

この本には、**本名を載せていません。** 表紙、奥付、EPUBの著者欄は、ペンネーム **NingentteWinner** です。KDPの著者名の欄にも、同じ名前を入力します（出版後は、Amazonの商品ページに表示されます）。

- 名前を変えたいときは、`book/kdp/book.json` の `author`、`publisher`、`copyright` を書き換えて、表紙とEPUBを作り直す（`book/README.md` の「作り直し」）。
- KDPの本人確認、税務、口座には、あなた自身の情報を登録しますが、それは公開されません。

## 手順

### 1. アカウントと、お金の情報（あなた自身で）
1. <https://kdp.amazon.co.jp/> を開き、Amazonのアカウントでサインインする。
2. 「著者情報」を入力する（氏名、住所、電話番号）。
3. **銀行口座**を登録する。
4. **税務情報**のインタビューに答える。**これらは個人情報です。AIには入力させず、自分で入力してください。** 内容に迷ったら、KDPのヘルプか、税務の専門家に聞いてください。

### 2. EPUBを、Kindleで確認する
アップロードの前に、**Kindle Previewer**（Amazonが配布している無料のツール）で、EPUBを開いて確認します。KDPのヘルプで「Kindle Previewer」を探して、入手してください。

確認すること：
- 目次から、各章に飛べる。
- 表（章1、7、11、12、付録B・Cなど）が、画面に収まって読める。
- コードのブロック（付録Dの依頼文）が、折り返して読める。
- 図（第10章）が、見える。
- 表紙が、正しく出る。

### 3. 本を登録する
1. 「本棚」→「**+ Kindle電子書籍**」。
2. **Kindle電子書籍の詳細**：`kdp-kit.html` の「1. 詳細」「2. キーワード」「3. カテゴリ」を、順に貼り付ける。
3. **AI生成コンテンツ**の質問に、**正直に**答える。この本の文章は、AI（Claude）が作成した原稿を、著者が確認・編集したものです。**テキストは「AI生成あり」と申告してください。** 画面の選択肢の文言に従います。
4. **Kindle電子書籍のコンテンツ**：原稿（EPUB）と、表紙（JPEG）をアップロードする。「ISBN」は不要。
5. **プレビュー**で、仕上がりを確認する。
6. **Kindle電子書籍の価格設定**：下の「価格の決め方」を参考に決める。
7. 「**Kindle電子書籍を出版**」を押す。

### 4. 審査と公開
- 出版のボタンを押すと、KDPの審査が始まります。**通常は、72時間以内を目安**として表示されます（画面の表示に従う）。
- 公開されると、Amazonの商品ページのURLが発行されます。
- 却下や修正の依頼が来たら、メールの本文に従って直し、**原稿を差し替えて**、再度出版します。

### 5. 公開後
- 「レポート」で、販売数とロイヤリティを見る。
- **本を更新したいとき**：原稿を直して、`python3 -I book/tools/build_epub.py` でEPUBを作り直し、KDPで「本の編集」→「コンテンツ」→ 原稿を置き換えて、保存して出版する。
- 審査の結果が分かったら、第12章のケーススタディの表（「執筆時点」と書いた行）を、結果に合わせて更新して、再公開するのがおすすめです。

## 価格の決め方

### 決まりごと（日本、公式ヘルプに基づく）

| ロイヤリティ | 価格の範囲（税込） | 計算 |
|---|---|---|
| 70% | **250円〜1,250円** | （税抜価格 − 配信料）× 70% |
| 35% | 99円〜20,000円 | 税抜価格 × 35%（配信料はかからない） |

（消費税は10%として計算。配信料は、ファイルのサイズで決まります。この本のEPUBは約0.4MBで、配信料は、ほぼ無視できる大きさです。**正確な金額は、価格の画面に表示されます。**）

### 価格ごとの、1冊あたりの印税の目安（70%、配信料を除く前）

| 価格（税込） | 税抜 | 70% の印税 | 35% の印税 |
|---|---|---|---|
| 500円 | 455円 | 約318円 | 約159円 |
| 780円 | 709円 | 約496円 | 約248円 |
| **980円** | 891円 | **約624円** | 約312円 |
| 1,250円 | 1,136円 | 約795円 | 約398円 |

### おすすめ

- **980円・70%ロイヤリティ**で始める。約4万字の実用書として妥当で、1冊あたりの印税も大きい。
- 売れ行きが伸びないなら、**780円**に下げる。**1,250円**が、70%を選べる上限。
- **KDPセレクト**に入ると、最初の90日は、Kindle Unlimitedの対象になります。その代わり、この期間は、他の電子書店で、同じ電子書籍を売れません。読まれたページ数に応じた収益になります。他の書店でも売る予定がなければ、最初は入るのも、選択肢です。
- 価格は、**いつでも変えられます**。

### 値付けで、やってはいけないこと
- 70%の範囲（250〜1,250円）の外の価格で、70%を選ぶ（選べません）。
- 他の書店で、もっと安く売る（KDPが価格の一致を求めることがあります）。

## 公開の前の、最後の確認

```
□ 原稿に、個人情報（住所、電話、鍵、本番のID）が載っていない
□ 他人の著作物、他社のロゴ、他人の顔写真を使っていない
□ AI生成のテキストであることを、KDPで申告した
□ 本の内容を、最新の画面で、もう一度確かめた（画面や規約は変わる）
□ 「審査の結果」の記述が、現在の状況と合っている
□ 表紙が、本の内容を、偽っていない
```
